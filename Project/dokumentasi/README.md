# Dokumentasi proyek

Folder ini menyimpan dokumentasi pengerjaan Particle Counter & Size Distribution Analyzer dengan sampel beras.

Lokasi: `/home/miq/Documents/ISV/Project ISV/Project/dokumentasi`.

## Isi yang disimpan

- Foto setup kamera, pencahayaan, latar, dan referensi ukuran.
- Screenshot aplikasi dan bukti pengujian manual.
- Catatan percobaan: tanggal, sumber gambar, jumlah manual, parameter, hasil, dan kendala.
- Bukti kalibrasi serta data galat dan pengukuran berulang ketika tersedia.
- Diagram blok, naskah laporan, dan dokumentasi video demo.

Gunakan nama berkas yang menjelaskan isi dan nomor percobaan, misalnya `setup_hp_01.jpg` atau `uji_roi_01.png`. Bedakan gambar dataset, citra gabungan sintetis, dan foto eksperimen fisik. Jangan mengisi hasil eksperimen yang belum dilakukan.

Gambar masukan untuk pemrosesan tetap disimpan di folder data proyek, sedangkan hasil otomatis aplikasi tetap di folder outputs. Tidak perlu memindahkan atau menggandakan semua data ke folder dokumentasi.
